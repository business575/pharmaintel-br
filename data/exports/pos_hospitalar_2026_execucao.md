| Risco | Impacto | Mitigação |
|---|---|---|
| Scripts de validação têm path hardcoded para Windows | Validação automatizada não roda em CI/Linux | Trocar `os.chdir('C:/...')` por path relativo — fix de 5 min |

| Sem log de envio | Não dá para classificar respostas — você tem que reportar manualmente cada resposta recebida | Criar tabela `outreach_log` no DB |
| `autonomous_sales_agent.py` aponta para leads file que não existe | Execução cega falha silenciosamente | Apontar para `hospitalar_2026_leads.csv` antes de qualquer rodada |
| Estratégia ainda usa template aprovado para feira, não para pós-feira | Subótimo — follow-up tem que reconhecer que feira já passou | Templates de follow-up pós-feira já existem no top7_strategy.md, basta usar |
